# AdLearn Pro

AdLearn Pro is a static, browser-based Google Ads demo simulator built to help users understand campaign planning, keyword research, ad copy testing, and budget optimization in a simplified marketing dashboard.

## Features

- Campaign dashboard with KPIs and trend cards
- Google Ads-style ad preview builder
- Campaign creation wizard
- Keyword planner with suggestions and competition indicators
- Budget simulator with adjustable sliders
- Responsive UI for demo and presentation use

## Project structure

- `googleadsimulater.html` — main simulator app
- `index.html` — entry page for easier access / hosting
- `README.md` — project overview and usage guide

## Run locally

Since it is a static HTML app, you can run it in any of the following ways:

1. Open `googleadsimulater.html` directly in a browser, or
2. Serve the folder locally:

```bash
python -m http.server 8000
```

Then visit:

- http://localhost:8000/

## Notes

This project is intentionally lightweight and designed for learning, demo, and presentation purposes. It does not include backend services or live ad platform integration.
